## 🧠 Key Concepts

| Concept | Description |
|---------|-------------|
| **Automation Mesh** | Distributed overlay network for running automation across multiple nodes |
| **Controller Node** | Node that manages and dispatches automation jobs |
| **Execution Node** | Node that runs the automation jobs |
| **Hop Node** | Node that relays traffic across network boundaries and air-gapped environments |
| **Receptor Networking** | Secure communication layer connecting mesh nodes |
| **SSL Certificates** | Certificate-based authentication securing mesh communication |
