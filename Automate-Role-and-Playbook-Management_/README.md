## 📋 Lab Summary

In this comprehensive lab, you built a complete **Ansible role**, used it through multiple playbook configurations and variable sources, and tested it across different scenarios — conditional logic, variable precedence, and performance validation.

> 🎯 **Focus:** Creating modular, reusable automation components that can be easily maintained and scaled across different environments.

## 🧠 Key Concepts

| Concept | Description |
|---------|-------------|
| **Role Directory Structure** | Standard layout including tasks, handlers, templates, variables, and metadata |
| **Variable Precedence** | The rules determining which variable source wins in complex scenarios |
| **Handlers** | Tasks triggered by changes within a role |
| **Templates** | Files rendered with variables to adapt configuration to each environment |
| **Role Testing** | Validating conditional logic, variable behavior, and performance |
